## 2. ゲーム進行要件
- 本ゲームは **sky01〜sky10 を用いた10段階**（各段階でモデルを出現・撃破）ののち、**11段階目として結果（スコア）画面** を表示する。
- 結果画面では sky として `IMG_20260405_507.jpg` を表示する。
- 既存のタイマー / スコア / コンボ / BGM / 効果音 / ランキング等の挙動は維持する。

## 3. モデル表示要件
- モデルの表示位置は、以下の9点から **ランダム** に選択する。
  - `{ x: -5, y: 0,  z: -5 }`
  - `{ x: 0,  y: 0,  z: -7 }`
  - `{ x: 5,  y: 0,  z: -5 }`
  - `{ x: 7,  y: 0,  z: 0  }`
  - `{ x: 5,  y: 0,  z: 5  }`
  - `{ x: -7, y: 0,  z: 0  }`
  - `{ x: 0,  y: 0,  z: 7  }`
  - `{ x: -5, y: 0,  z: 5  }`
  - `{ x: -2, y: -1, z: 1  }`
- モデルの向きは、**カメラの方を向く**（yaw 回転のみで計算）。
- モデルのスケールは全位置共通で **0.5**（ユーザー確認済み）。

## 4. 制約・非破壊要件
- 現在正常に動作している他の箇所（スコア計算、コンボ、BGM、効果音、ランキング、ボール発射、当たり判定、フェード遷移、VR入退場）へ **影響を与えないこと**。
- 変更は sky 定義・ステージ設定・モデル配置ロジックの範囲に限定する。
